## Interpretation

1. **Cloudflare panel (P1/P2)**: the only difference between Arm 1 and Arm 2
   is the shim (same flags, same BiDi input method, same IP/day). Raw
   challenges, shim passes, flag-free passes. `navigator.webdriver` (or the
   descriptor surface the shim rewrites) is a sufficient trigger for these
   two Cloudflare challenges here, and the pinned shim removes it. Build
   unnecessary for this class.
2. **Google entry**: flag-free passes, both flagged arms blocked, shim does
   not help. Caveat, stated plainly: Arm 3 typed via real keyboard events
   (computer-use act-now), Arms 1/2 via BiDi `input.performActions`. The
   Google difference may be flags, BiDi session presence, input method, or a
   mix; this gate does not isolate which. It does isolate that
   webdriver=false alone (shim) does not clear Google.
3. **namechk**: CAPTCHA at site-search in every arm including flag-free.
   Not a webdriver effect; do not count it for or against the build.
4. **P3/P5/C1/C2**: pass in every arm. R3-024's openverse block did not
   reproduce in any throwaway arm today (live-Zen profile/history effects
   remain possible; owner-browsing arm was kept separate per spec).

## Caveats

- One machine, one IP, one morning, n=1 per arm per site (plus Arm 1b P1/P2
  repeat). Cloudflare scoring is probabilistic; treat PASS/CHALLENGE as
  today's readings, not guarantees.
- Arm 3 reads are screenshot-based (no BiDi on a flag-free browser); Arms
  1/2 reads are BiDi DOM reads + screenshots. Outcome markers were the same
  (challenge titles/text vs target content).
- Fresh headed profiles: BiDi `session.new` fails ("session not created")
  until the browser is restarted after first-run completion; then it works.
  Noted for future throwaway work.
- A concurrent split-gate lane held ws2 focus early on; flagged arms were
  driven over BiDi (focus-independent) after that. No owner tabs/windows
  were closed or navigated. Test windows were closed by recorded PID +
  cmdline profile check only (compositor window-close ban honored).
- No personal info in this report; the Google block page's IP line is
  redacted from evidence summaries.
